SQL Sub-Language Hierarchy

Interactive map of SQL command structures (Inspired by architectural diagrams).

  • SQL

    Structured Query Language

    • DDL

      Data Definition Language

      • CREATE

        Builds new db/tables

      • ALTER

        Modifies table structure

      • DROP

        Deletes objects entirely

    • DML

      Data Manipulation Language

      • INSERT

        Adds new rows/data

      • UPDATE

        Changes existing data

      • DELETE

        Removes specific rows

    • DQL

      Data Query Language

      • SELECT

        Retrieves specific data

    • DCL

      Data Control Language

      • GRANT

        Gives user access

      • REVOKE

        Removes user access

    • TCL

      Transaction Control

      • COMMIT

        Saves changes permanently

      • ROLLBACK

        Undoes recent changes

❔ Quick Guide

How to use this site

Classify SQL commands, understand what each command category means, and download a report of your results.

Using the Query Workspace

STEP 01
Enter SQL commands
Type or paste one or more SQL commands into the editor. Separate multiple commands with a semicolon (;).
STEP 02
Execute & Classify
Click “Execute & Classify”. The site verifies standard SQL syntax and identifies each command as DDL, DML, DQL, DCL, TCL, or flags syntax errors.
STEP 03
Read the results
Check the result list for each command. The category legend below highlights the categories found in your query workspace.
STEP 04
Download the report
After a successful classification, click “Download Report” to save a text report containing the query, classifications, counts, and timestamp.

What the categories mean

DDL
Defines or changes database structures — CREATE, ALTER, DROP, TRUNCATE, RENAME.
DML
Changes data stored in tables — INSERT, UPDATE, DELETE, MERGE.
DQL
Retrieves data — SELECT and WITH queries.
DCL
Controls permissions — GRANT and REVOKE.
TCL
Controls transactions — COMMIT, ROLLBACK, SAVEPOINT.
