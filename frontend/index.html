Module 1 – SQL Fundamentals Concept

SQL commands are strictly grouped into five major categories based on their functional objectives within a Relational Database Management System (RDBMS):

[STANDARD SQL ENGINE] ├── DDL (Data Definition) : Modifies schema structure (CREATE, ALTER, DROP, TRUNCATE) ├── DML (Data Manipulation) : Manages row-level data (INSERT, UPDATE, DELETE) ├── DQL (Data Query) : Retrieves target data (SELECT) ├── DCL (Data Control) : Manages access security (GRANT, REVOKE) └── TCL (Transaction Control): Manages session states (COMMIT, ROLLBACK)

User Manual / Help

Welcome to the SQL Command Classifier. This application utilizes a custom Node.js backend parsing engine to evaluate raw SQL strings and categorize them into standard RDBMS structures.

How to operate the system:

  1. Navigate to Input: Open the "Query Classifier" tab.
  2. Provide Input: Type or paste any valid SQL command into the text box. (Note: You can batch-process multiple commands by separating them with a semicolon ;).
  3. Process Command: Click the blue Execute Parser button.
  4. Interpret Output: Review the Output Console below. It will dynamically generate a classification card for every valid command detected.
  5. Generate Log: Click the Download Report button to save a .txt execution log.
