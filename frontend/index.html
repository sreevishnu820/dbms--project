SQL Fundamentals

SQL commands are grouped into five core categories based on their purpose within a relational database system.

[STANDARD SQL ENGINE] ├── DDL (Data Definition) : Modifies schema structure (CREATE, ALTER, DROP, TRUNCATE) ├── DML (Data Manipulation) : Manages row-level data (INSERT, UPDATE, DELETE) ├── DQL (Data Query) : Retrieves target data (SELECT) ├── DCL (Data Control) : Manages access security (GRANT, REVOKE) └── TCL (Transaction Control): Manages session states (COMMIT, ROLLBACK)

User Manual

Welcome to the SQL Command Classifier. This application uses a custom Node.js backend to evaluate SQL statements and classify them into standard DBMS command categories.

1

Open the editor

Navigate to the Query Classifier tab and paste or type your SQL command.

2

Run the parser

Use the Execute Parser button to classify each statement in the batch.

3

Review results

Inspect the cards and filter them by DDL, DML, DQL, DCL, and TCL categories.

4

Export report

Download the report for documentation, evaluation, or project submission.
