Using the query workspace

            
Classify SQL commands, understand each category, and download a report of your results.

          

        

        

          

            

              
Enter SQL commands

              
Type or paste one or more commands into the editor. Separate multiple commands with a semicolon (;). Comments starting with -- are ignored.

            

            

              
Execute and classify

              
Select Execute & classify or press Ctrl + Enter. Each statement is checked against standard SQL syntax and labelled DDL, DML, DQL, DCL, TCL, or flagged as a syntax error.

            

            

              
Review the results

              
Open any result to see its keyword, purpose, database effect, analysis, and a ready-to-run Python snippet. Select a category tile to filter by DDL, DML, DQL, DCL, or TCL. Recent queries are saved so you can reload them.

            

            

              
Download the report

              
After a run, select Download report to save a text file with the commands, classifications, counts, and timestamp.

            

          

        

      


      

        

          

            
What the categories mean

          

        

        

          

            
DDL
Data Definition Language
Defines or changes database structures.
CREATEALTERDROPTRUNCATERENAME

            
DML
Data Manipulation Language
Changes data stored in tables.
INSERTUPDATEDELETEMERGE

            
DQL
Data Query Language
Retrieves data.
SELECTWITH

            
DCL
Data Control Language
Controls permissions.
GRANTREVOKE

            
TCL
Transaction Control Language
Controls transactions.
COMMITROLLBACKSAVEPOINT

Privacy policy
Last updated October 2026

        

          
1. Data processing

          
This application processes SQL query strings locally in your browser or through an internal local server connection. No personal user data or proprietary query content is sent to external commercial telemetry services.

          
2. Local storage

          
The application stores your theme choice and your five most recent queries in local browser storage only. This keeps your settings and history consistent between sessions. You can remove saved queries at any time with Clear history.

          
3. Contact

          
For questions about data practices, contact the system administrators at Vellore Institute of Technology, Chennai.
