# SQL Command Classifier & DBMS Learning Suite

> **Live Website:** [https://sreevishnu820.github.io/dbms--project/](https://sreevishnu820.github.io/dbms--project/)

An interactive web application for learning and mastering Database Management Systems (DBMS).

### Features
- **SQL Classifier & Strict Syntax Checker:** Real-time classification into DDL, DML, DQL, DCL, and TCL with strict grammar parsing.
- **Linear Probing Simulator:** Interactive hash table collision visualizer with step-by-step probing traces, collision badge, clustering demos, and tombstone handling.
- **AI Practice & Quiz Arena:** Interactive DBMS mentor personas (Prof. Codd, CodeCraft, QuizMaster Pro) with 30+ quiz questions and 20 practice challenges.
- **Learning & Resources:** SQL hierarchy mind map, curated YouTube masterclasses, and book references.
